# 四角色 Ultra 神性版素材来源

本目录包含用户于 2026-11-04 确认并授权随 CodexStyle v1.3.36 发布的四张 Ultra 新图，以及从 v10 原样沿用的 20 张 low / medium / high / xhigh / max 图片。

- 四张 Ultra 使用 OpenAI 内置图像生成工具生成，分别延续白龙、深海鲸灵、琥珀书庭与星穹猫娘的角色身份，以神圣空灵、神光和超然形态表现最高档。它们均为 1672 × 941 的静态 PNG。
- 角色参考来自用户在对话中提供的设定图；参考图、原始对话、生成提示词和本机主题库数据不随本包分发。
- 普通背景继续复用各组 low 发行资产。四个 themeId、名称、描述、配色、阅读配置以及 low 至 max 的图片字节全部保留 v10 原值，仅 Ultra 图片更新。
- `catalog.json` 固定声明全部图片的 SHA-256。运行时复用既有媒体格式、完整解码、尺寸、单图 10 MiB 及普通背景加档位图片合计 32 MiB 的校验。
- 本包替代 `mascot-redesign-2026-11-04-v10`，不引入新主题。普通背景哈希不变，因此 `previousImageSha256` 为空；`previousFingerprints` 固定为对应未编辑 v10 主题的完整内容指纹。
- v10 基线指纹由其发行 catalog 的名称、描述、配色、画面、样式、首页卡片、普通背景和六档图片哈希，经既有 `writeThemeConfiguration`、`generateConfiguredCss` 和 `themeFingerprint` 计算，不使用本机主题库或 MCP 更新后的用户配置。
- 原子升级沿用现有 secure-store 流程：先暂存新 UUID 资产，再统一提交索引；保留主题库 ID 和选择，用户编辑、草稿、恢复点及已删除主题不覆盖、不复活。历史 v7 / v8 / v9 / v10 发行资源保持原样。
